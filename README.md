# EesyLoad Rider

Glass, map-first booking UI. Structure stolen from Tesla/Apple: map owns the screen, one sheet, one CTA.

## Open it

```bash
git clone https://github.com/appinnovationmc-stack/eesyload-rider.git
open www/index.html
```

Or from your existing rider project:

```bash
cp www/index.html /Users/maobane/eesyload-rider/www/book-glass.html
open /Users/maobane/eesyload-rider/www/book-glass.html
```

This screen is the new booking surface. Pickup/dropoff, vehicle, price and Book load. Not wired to Supabase yet.
